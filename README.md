# LegDay — Sofía Duz · Entrenamiento Personal

Sitio web oficial de **LegDay**, el programa de entrenamiento personal y nutrición de Sofía Duz, Buenos Aires.


```
legday-sofia/
├── index.html        # Sitio completo (HTML + CSS + JS inline)
├── _headers          # Headers HTTP para Cloudflare Pages
├── _redirects        # Redireccionamientos para Cloudflare Pages
├── .gitignore
└── README.md
```

##  Features

- Hero section con foto y título editorial
- Sección Sobre Mí
- Galería de resultados
- Planes de entrenamiento con tabs (Presencial / A Distancia)
- Sección de contacto con formulario
- Instagram feature (LegDay + Nutri)
- Totalmente responsive



##  Tecnologías

- HTML5 + CSS3 + Vanilla JS
- Google Fonts: Cormorant Garamond + Jost
- Sin dependencias ni build tools

##  Imágenes

Las imágenes del hero, about y galería apuntan a URLs externas (Unsplash/Pexels como placeholders). Reemplazarlas con fotos reales de Sofía antes del lanzamiento.
